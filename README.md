# skydome backend
backend for the skydome ecommerce website built with express js

## 🚀 Features
- generate payment functionality with paystack
- verify payment functionality with paystack

  
## 📋 Prerequisites

- Node.js 10+ 
- npm or yarn

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/tobiayinmiro23/skydome-backend.git
   ```

2. **Enter the directory**
   ```bash
   cd skydome-backend
   ```
   
3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm start
   ```


## 📚 API Documentation

- `GET /` - Check status of server
- `POST /pay` - Create new payment
- `POST /verify` - Verify payment



## 📦 Dependencies

- **cors**:  *for cross origin resource sharing*  
- **dotenv**:  *for handling enviromental variables*  
- **nodemon**:  *for handling server develpoment process*
